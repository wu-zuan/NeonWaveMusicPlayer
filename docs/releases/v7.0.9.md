NeonWave 的桌面宿主已遷移至 Tauri 2，保留既有 React 介面、播放流程、音效、歌單格式與成熟的 Node.js 服務。

- Windows 安裝檔沿用既有安裝位置及使用者資料，首次啟動會匯入舊版設定，保留原始資料。
- WebView2 使用系統 runtime；缺少時才連線下載，不內附離線安裝包。使用者不需另裝 Node.js。
- 原有 IPC、迷你播放器、Discord／Listening Party、歌詞、下載與系統整合已移至 Tauri commands、events 及 Node sidecar。
- 更新檔採用 Tauri 簽章，並提供舊版更新器需要的 YAML。既有 Windows 使用者可透過原本更新流程取得新版。

Windows 10 已完成主要播放、資料及安裝流程驗證。Windows 11 的 Snap／多螢幕 DPI，以及 macOS、Linux 的完整桌面操作仍待實機驗收；Discord 實際語音連線、GPU 模型辨識與特殊企業網路也需依使用環境確認。

Windows 安裝檔具有更新器簽章，目前未使用 Authenticode 發行者憑證。詳細遷移對應與驗收範圍請見 [遷移紀錄](https://github.com/wu-zuan/NeonWaveMusicPlayer/blob/v7.0.9/docs/tauri-migration.md)。
